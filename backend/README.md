# SkyPakistan Airways - Backend

Backend for SkyPakistan Airways reservation system. Phase 1 scaffold: server, auth, DB connection, seed script.

Quick start (development):

1. Copy `.env.example` to `.env` and update values.
2. Install dependencies:

```
cd backend
npm install
```

3. Run in dev mode:

```
npm run dev
```

4. Seed demo accounts:

```
npm run seed
```
